# وكيل — وكيل ذكاء اصطناعي للشركات

وكيل واحد يخدم أي عدد من الشركات. كل شركة لها وكيل خاص فيها يعرف معلوماتها، ويشتغل على **واتساب** و**موقع الشركة**:

- **خدمة العملاء:** يجاوب من معلومات الشركة فقط، وما يخترع.
- **تأهيل العملاء:** يسأل أسئلة التأهيل ويصنّف العميل (جاهز / مهتم / يستكشف) ويحفظه.
- **حجز المواعيد:** يحجز حسب أوقات العمل ويمنع التعارض.
- **التحويل لموظف:** وقت الشكوى، أو لما العميل يطلب إنسان، أو يجيه سؤال خارج معلوماته.
- **مساعد داخلي للموظفين:** صفحة خاصة يدخلها الموظف برمز.
- **لوحة تحكم:** تضيف فيها الشركات وتعدّل معلوماتها، وتشوف العملاء والمواعيد والمحادثات، وتتحكم بالتجربة المجانية (14 يوم، وبعدها يوقف الوكيل تلقائي لين تحوّله لمدفوع).

## التكلفة: صفر

| الأداة | الاستخدام | المجاني |
|---|---|---|
| Google Gemini | عقل الوكيل | فيه free tier ما ينتهي، بحدود يومية |
| Supabase | قاعدة البيانات | الخطة المجانية |
| Vercel | الاستضافة | خطة Hobby |
| WhatsApp Cloud API | واتساب | أول 1000 رد خدمة شهريًا لكل رقم مجانية |

> تنبيه: Gemini المجاني يستخدم البيانات لتحسين منتجاتهم، وحدوده محدودة. هذا يكفي للتجربة والعروض. لما توقّع أول عميل مدفوع فعّل الفوترة في Google AI Studio، والتكلفة بسيطة جدًا مع نماذج Flash.

## التشغيل (حوالي 30 دقيقة)

### 1) Supabase
1. أنشئ مشروع جديد في supabase.com
2. افتح **SQL Editor**، والصق محتوى `supabase.sql` كامل، واضغط Run (ينشئ الجداول وشركة تجريبية اسمها `demo`).
3. من **Project Settings > API** خذ: `Project URL` و `service_role key`.

### 2) Gemini
خذ مفتاح مجاني من aistudio.google.com/apikey

### 3) Vercel
1. ارفع المجلد على GitHub (مستودع خاص).
2. في Vercel: **Add New > Project**، اختر المستودع، Framework = **Other**.
3. في **Environment Variables** حط القيم اللي في `.env.example`:
   `GEMINI_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_PASSWORD`, `WA_VERIFY_TOKEN`
4. Deploy.

بعدها:
- `https://مشروعك.vercel.app` ← صفحة تعريفية، ومعها الوكيل التجريبي شغّال
- `/admin.html` ← لوحة التحكم
- `/internal.html?company=demo` ← المساعد الداخلي (الرمز التجريبي: 1234)

### 4) واتساب
1. في developers.facebook.com أنشئ App من نوع **Business**، وأضف منتج **WhatsApp**.
2. من **API Setup** خذ: `Phone number ID` و `Access token` (للتجربة فيه رقم اختبار مجاني من Meta. للإنتاج اربط رقم الشركة وسوِّ System User token دائم).
3. حط التوكن في Vercel باسم `WA_TOKEN` ثم Redeploy.
4. في **Configuration > Webhook**:
   - Callback URL: `https://مشروعك.vercel.app/api/whatsapp`
   - Verify token: نفس قيمة `WA_VERIFY_TOKEN`
   - اشترك في حقل `messages`
5. في لوحة التحكم، افتح إعدادات الشركة وحط `Phone number ID`.

كل شركة تقدر يكون لها رقم واتساب خاص فيها. اربط كل رقم بنفس الـ App، وحط Phone number ID حقه في إعدادات الشركة.

## إضافة شركة جديدة (عميل تجربة)
1. لوحة التحكم > **+ شركة جديدة**
2. عبّي معلوماتها: الخدمات والأسعار والأسئلة الشائعة وأوقات العمل وأسئلة التأهيل. **جودة الوكيل على قد جودة هذي المعلومات.**
3. احفظ، وافتح تبويب **التركيب** وانسخ سطر الويدجت لموقعهم.
4. التجربة تنتهي تلقائيًا بعد 14 يوم. إذا دفع العميل غيّر الباقة إلى «مدفوعة».

## هيكل الملفات
```
api/chat.js       محادثة الموقع والمساعد الداخلي
api/whatsapp.js   Webhook واتساب
api/admin.js      لوحة التحكم (محمية بكلمة مرور)
api/company.js    إعدادات الويدجت العامة
lib/agent.js      عقل الوكيل: التعليمات، الأدوات، الذاكرة
widget.js         ويدجت الموقع (سطر واحد يتركب في أي موقع)
admin.html        لوحة التحكم
internal.html     المساعد الداخلي
index.html        صفحة تعريفية + عرض حي
supabase.sql      قاعدة البيانات
```

- الحماية: كل الجداول مقفلة، وما يوصلها إلا السيرفر. المتصفح ما يشوف المعرفة الداخلية ولا بيانات العملاء.
- يقرأ النصوص فقط حاليًا. الصوتيات والصور مرحلة ثانية.
